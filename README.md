# 麻辣湯ログ（MalatangLog）

最高の一杯を、もう忘れない。
プロダクト仕様書 v1.0（2026-07-28 承認版）の P0 と、追加開発指示書 v1.1 を実装した iOS アプリです。

> GitHubへのPushから自宅MacでのBuild、Archive、TestFlightアップロードまでの
> 自動化手順は [Docs/REMOTE_DEVELOPMENT.md](Docs/REMOTE_DEVELOPMENT.md) を参照してください。

- 端末内保存のみ（SwiftData）。アカウント・独自サーバー・広告・分析SDKなし
- MapKitで現在地から約3kmの麻辣湯店を地図表示。Google／Apple マップの外部起動にも対応
- 300円買い切り想定。アプリ内課金の実装なし

---

## 1. 開いてビルドする

```
MalatangLog.xcodeproj
```

- **Xcode 16 以降が必要**です（同期フォルダ形式のプロジェクトを使用）
- 対応OS: iOS 17.0 以降
- Swift 5 モード。外部ライブラリ・SPM依存はゼロ

シミュレータで動かすだけなら、開いて ⌘R で起動します。

## 2. iPhone 実機に入れる手順

1. iPhone を Mac に接続（またはWi-Fi同期を有効化）し、iPhone側で「このコンピュータを信頼」
2. Xcode で `MalatangLog` ターゲット → **Signing & Capabilities**
   - **Team** に自分の Apple ID を選ぶ（無料アカウントで可。未登録なら Xcode → Settings → Accounts で追加）
   - **Automatically manage signing** にチェック
   - **Bundle Identifier** は `com.malatanglog.app`。他人と衝突したら `com.自分の名前.malatanglog` などに変更
3. 画面上部の実行先で **iPhone 16e** を選ぶ
4. ⌘R で実行
5. 初回は iPhone 側で **設定 → 一般 → VPNとデバイス管理 → デベロッパApp** から自分の証明書を信頼

> 無料の Apple ID で署名した場合、アプリは **7日で期限切れ**になります。使い続けるには再度 ⌘R で入れ直すか、有料の Apple Developer Program（年 $99）に登録してください。

## 3. テストを走らせる

⌘U で実行。カバーしている主な観点:

| ファイル | 検証内容 |
|---|---|
| `FrequentIngredientsTests` | よく使う具材の並び（固定優先／直近30杯／同数時の最終使用日時／非表示除外） |
| `ServingDuplicationTests` | 「この一杯をもう一度」で元データが変わらないこと、入力検証 |
| `MasterServiceTests` | 初期マスター件数・同名重複なし・別名一致・改名時のID維持・非表示後も過去記録が壊れない |
| `BackupServiceTests` | エクスポート→復元の往復、同じバックアップ2回で重複スキップ、全置換、壊れたファイルの拒否 |
| `CatalogSearchTests` | 中国語別名を含む検索、絞り込み、価格順の未入力の扱い |
| `AnalyticsSummaryTests` | 集計（平均価格から未入力を除外、分布） |
| `MapLauncherTests` | 緯度経度あり／店名のみ／Googleマップ未インストール時のフォールバック |

## 4. 構成

```
MalatangLog/
├─ Models/        Serving / Store / Ingredient / Noodle / Soup, VersionedSchema
├─ Data/          初期マスター、よく使う具材ロジック、写真保存、バックアップ
├─ Design/        配色・タイポ・共通部品（タグ、辛さ痺れ、星、湯気）
├─ MapKitSupport/ 現在地・周辺店舗検索・外部地図URL
└─ Features/      Home / Record / Catalog / Analytics / Settings
Supporting/Info.plist   権限文言・Googleマップスキーム・.malaarchive の型宣言
```

### 実装済みの P0

- 端末内データモデル、写真保存、マイグレーション基盤（`MalatangSchemaV1` + `MalatangMigrationPlan`）
- 新規記録・編集・削除、クイック入力、詳細の折りたたみ
- スープ／辛さ／痺れ／麺／具材マスターと自由追加（重複防止つき）
- よく使う具材8件の自動更新と長押し固定・非表示
- いつもの一杯（店舗ごと最大3件）、殿堂入り、この一杯をもう一度 → 注文メモ → 今日の記録を作成
- 図鑑（写真グリッド2列）、並び替え4種、絞り込み、別名込みテキスト検索、店舗別画面
- MapKit 店舗検索、Google／Apple マップ外部連携（座標なしは店名検索にフォールバック）
- ホーム／地図／一覧／分析の4タブ、訪問済みピン、お気に入り店舗、地図からの記録
- 時系列カード一覧、店舗検索、評価・辛さ・価格・お気に入りフィルター
- 殿堂入り、ルールベースの「今日のおすすめ」、今月の杯数・平均価格
- 初回サンプル「Legendary Bowl」（同梱写真は後から差し替え可能）
- ライト／ダーク／端末設定に追従する外観切り替え
- バックアップ・復元（`.malaarchive`、追加／全置換の二段階確認、重複IDスキップ）
- 分析（3件未満はグラフを出さない）、設定、プライバシー説明、不具合報告テキスト

### 意図的に実装していないもの（仕様の「初版でやらないこと」）

フォロー・口コミ・ランキング、独自サーバー、ログイン、クラウド同期、
プッシュ通知、AI推薦、Google Maps SDK / Places API の直接利用。

## 5. 設計上の判断メモ

- **データを失わないことを最優先**。DBを開けなかったときに黙ってメモリ内保存へ落とさず、`DataUnavailableView` で状態を伝える（記録が消えたように見える事故を避けるため）
- **具材・麺・スープは物理削除しない**。参照中は「非表示」のみ。改名してもUUIDを維持するので過去記録が壊れない
- **バックアップは FileWrapper のシリアライズ表現**を使い、写真込みで1ファイルに見せている。ZIPライブラリ等の外部依存が不要
- **初期マスターの重複を排除**。仕様書の一覧にあった `えび団子`（海鮮／練り物）、`湯葉`と`腐竹`、`干豆腐`と`豆腐皮`/`千張`/`豆腐干`、`揚げパン`と`油条`、`米粉`と`米線`、`板春雨`と`寛粉` などは、表示名を1つに絞って残りを **別名（検索対象）** に寄せた。結果は具材148件・麺17件・スープ11件（仕様の120〜160／15以上／10以上を満たす）
- **写真は引き継がない**。「この一杯をもう一度」で複製する際、写真と評価はリセットする（今日の一杯は今日撮る）
