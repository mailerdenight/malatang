# 公開Webページ

このリポジトリのGitHub Pagesが https://mailerdenight.github.io/malatang/ を公開しています。ユーザーサイト側の同じURLよりこちらのプロジェクトPagesが優先されます。

index.html, support/index.html, privacy/index.html は mailerdenight/mailerdenight.github.io の malatang/ 配下と同一内容です。共通CSS・JavaScript・正式アイコンはユーザーサイトの /support-ui/ と /assets/app-icons/ を参照します。

Webページを更新する際は、両リポジトリの該当HTMLを同期し、公開URLを確認してください。同じURLへの移転案内は自己転送になるため使用しないでください。旧 privacy.html から privacy/ への転送は維持します。
