# 多言語・世界地図対応の判断記録

更新日: 2026-08-03

## 結論

国ごとに別アプリを作らず、1つのiOSアプリに次の9ロケールを同梱する。

| ロケール | 対象 |
|---|---|
| `ja` | 日本語 |
| `en` | 英語（非対応言語のフォールバックを兼ねる） |
| `vi` | ベトナム語 |
| `ko` | 韓国語 |
| `zh-Hans` | 簡体字中国語 |
| `zh-Hant` | 台湾向け用語を使った繁体字中国語 |
| `th` | タイ語 |
| `de` | ドイツ語 |
| `id` | インドネシア語 |

iOSが端末の優先言語またはユーザーが選んだアプリ言語に合わせて、自動的にローカライズを選択する。`zh-TW` の端末は `zh-Hant`、`zh-CN` は `zh-Hans` に解決される。

## 市場選定

- ユーザー指定の韓国語、簡体字中国語、台湾向け繁体字中国語を最優先とした。
- 追加市場は「麻辣湯の実店舗」「iOSへの到達性」「既存の英語・中国語で代替しにくいか」を比較し、タイ語、ドイツ語、インドネシア語を選んだ。
- 張亮麻辣湯の公式店舗一覧ではタイ25店、インドネシア4店などが掲載され、ブランド全体では20か国超へ展開している。
- ドイツ語はドイツだけでなくオーストリアにも再利用でき、欧州で確認できる麻辣湯店舗密度とiOS到達性を評価した。
- マレー語も候補になったが、マレーシアは既存の英語・簡体字／繁体字中国語でカバーできる割合が比較的高いため見送った。

## チーム協議メモ

- 東南アジア調査担当: タイは実店舗数が突出。次点は人口と成長性からインドネシア。マレー語は英語との差分が小さい。
- 市場担当: iOS利用と欧州の店舗密度を加味するとドイツ語を落とす理由が弱い。3言語追加できるならタイ語、ドイツ語、インドネシア語が最良。
- 実装担当: `*.lproj` の静的な文字列だけで追加でき、翻訳APIや独自サーバーは不要。中国語は文字変換だけでなく、簡体字と台湾向け繁体字を別々に翻訳する。
- 地図担当: 店名検索語にベトナム語とタイ語を追加。都市名のジオコーディングは日本語、簡体字、繁体字、韓国語、タイ語の文字体系に合わせる。
- QA担当: 全言語で同一キー、書式指定子、権限説明を機械検査し、主要画面はシミュレータで目視確認する。
- 最終判断: 追加API費用を発生させず、9言語を1つのアプリとして出す。

## 地図と費用

- アプリ内地図と店舗検索はiOS標準のMapKitを使用する。別の地図SDKや独自店舗サーバーは追加しない。
- Googleマップ連携はHTTPSのMaps URLで外部アプリまたはブラウザを開く。Google公式の仕様上、この方式はAPIキー不要。
- Apple Mapsに店舗がない地域でも、地図中央の座標を使った店舗の手動登録を可能にする。
- 地図のPOI網羅性は国や地域によって異なる。無料構成では完全な世界店舗データベースを保証せず、検索語の多言語化と手動登録で補う。

参考:

- [Apple MapKit](https://developer.apple.com/documentation/mapkit)
- [Google Maps URLs（APIキー不要）](https://developers.google.com/maps/documentation/urls/get-started)

## 容量と残る課題

追加6言語（韓国語、簡体字、繁体字、タイ語、ドイツ語、インドネシア語）のコンパイル済みリソースは、2026-08-03のシミュレータ用Debugビルドで合計181,306 bytes（約0.17 MiB）だった。同ビルドの非圧縮アプリ本体34,573,517 bytesに対して約0.52%である。App Store配信時の圧縮・App Thinning後のサイズは端末ごとに異なる。画像、翻訳SDK、オフライン地図は同梱しない。

価格入力は為替換算を行わない。基準通貨は初回起動時にアプリ言語から決め、最初の記録を保存する前だけ設定画面で変更できる。記録が1件でも入った後は通貨を変更できない。各記録には `currencyCode` を保存し、バックアップ復元などで設定値と記録値がずれた場合は最初の実記録の通貨を基準通貨として扱う。平均価格や価格フィルターは基準通貨と一致する記録だけを対象にし、異なる通貨を混在集計しない。
